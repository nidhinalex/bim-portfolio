A note before we start

Why this is a walkthrough, not a screen share

Every tool here was built for Livio Building Systems' live production pipeline. The code and the model files are Livio's property, so what follows is what each tool does, why it was built, and what changed as a result — described directly, not demoed from a running file. Three of them also have public, non-proprietary demos on my own GitHub portfolio, linked where they appear.

The underlying story is the same across all 94:

Spot the repetitive manual task
STEP 02
Automate the geometry / data
STEP 03
Add validation, not just speed
STEP 04
Package as a reusable tool
STEP 05
Integrate into the team's workflow

Panel Backing Check

What it does

Reads each wall board's real 3D solid geometry — not a simplified bounding box — and tests it segment-by-segment against nearby framing to report exactly which stretches of the panel lack backing support.

Why it matters

Turns a manual visual inspection into a few clicks, and catches gaps a bounding-box shortcut would miss entirely.

"I replaced a bounding-box shortcut with real solid-geometry analysis, because the simplified version was missing real gaps in support."
100s
of boards checked per project, automatically
C#
Revit API, solid geometry — segment-by-segment testing

Detail ⓘ 02 — MEP BIM Automation Live demo on GitHub

Panel-to-MEP Container Matching

What it does

Calculates real distance-to-solid from linked structural models to automatically match MEP elements — conduit, fixtures, electrical equipment — to the correct wall panel, then writes that panel identity back onto the element.

Why it matters

Removes a highly repetitive manual coordination step across every MEP element on a project, and prevents mis-assigned panels downstream.

"I automated understanding where an MEP element belongs in the structural model, rather than relying on someone to identify and assign it by hand."
11
MEP element categories handled — point-based and curve-based
Dynamo
custom nodes + C# Revit API

Layout Automation Suite

What it does

A three-command system: generates cropped, tagged views per panel; places full dimension strings along panel runs; and auto-tags every panel on a sheet.

Why it matters

A full day of manual layout work per panel run now takes minutes — with fully consistent results every time, not just faster ones.

"A full day of manual layout work per panel run now takes minutes — and it's not just faster, it's exactly repeatable every time."

HRS Sheet + View + Placement Automation

What it does

Chains view creation, view configuration, sheet creation and viewport placement into one automated documentation workflow for HRS (Hot Rolled Steel) framing.

Why it matters

On projects with hundreds of views and sheets, this saves hours of manual sheet-building per project and keeps every drawing layout consistent.

"I didn't just automate a single command — I automated the workflow from model information all the way to a structured drawing sheet."

Detail ⓘ 05 — Connection Detail Library

15 Parametric Connection Generators

What it does

Turns repetitive connection-detail drafting into automated, data-driven generation across 15 connection types — screw, plate, bolt and angle, across wall / floor / post / concrete combinations.

Why it matters

If a detail used to take 3–10 minutes by hand, hundreds of connections translate into many hours saved per project, with far more consistency between similar details.

"I built a library of reusable connection generators instead of drafting every connection detail by hand — this is my strongest example of building a system, not a script."
15
connection types: STS, WTW, FTF, WTF, FSW, BOP, CTW, POS, WSP, WOC, POC…
3–10m
manual minutes per detail, replaced

Detail ⓘ 06 — Framing QA/QC

Framing QA/QC Checker Suite

What it does

A set of checkers — Shear Plan, Shear Check, Nogging, Shear Blocker, Drop Slab, Floor Stiffener, Stud/Joist Spacing — that inspect the model for conditions that are easy to miss visually.

Why it matters

Moves QA/QC from pure visual inspection to repeatable automated checks, catching missing or misplaced framing before it reaches documentation or fabrication.

"The goal wasn't just to model faster — it was to make the model harder to get wrong."

distinct automated checkers in the suite

Detail ⓘ 07 — Framing QA/QC

OWJ Stud Adjuster

What it does

Reads the existing framing condition around an opening and automatically adjusts vertical or slanted studs to fit — including running the adjustment across multiple openings at once.

Why it matters

Replaces repetitive manual geometry edits and reduces the risk of incorrect framing around complex openings.

"This tool interprets the existing framing condition and makes geometry-aware adjustments, rather than just placing predefined objects."
2
modes: vertical stud & slanted stud, each with multi-opening batch runs
OWJ
Open Web Joist framing, geometry-aware
